# Provenance and public changes

This public edition is based on the author's NLP coursework archive, containing
seven Python scripts and a Greek technical report. Original assignments, raw
documents, screenshots, personal identifiers and local filesystem paths are not
part of the public repository. Third-party teaching material is not relicensed.

| Source script | Source purpose | Public location |
|---|---|---|
| erotima1.py | Uncased BERT NER | Shared training pipeline |
| erotima2.py | Qualitative word predictions | `predict` and evaluation JSONL |
| erotima3.py | Cased BERT NER | `--model google-bert/bert-base-cased` |
| erotima5.py | Frozen BERT encoder | `--freeze-encoder` |
| erotima6.py | POS tagging | `--task pos` |
| erotima7.py | Phrase chunking | `--task chunk` |
| erotima8.py | RoBERTa NER | `--model FacebookAI/roberta-base` |

The report's fourth question explains alignment and has no separate script.
Its copied table of contents does not reliably match the body, so historical
values are attributed to body questions Q1, Q3 and Q6.

## Deliberate changes

- Replaced duplicated scripts and import-time execution with a package and CLI.
- Removed hardcoded local paths and the silent unknown-label fallback.
- Added strict four-column parsing, gold tag normalisation and coverage checks.
- Replaced truncation and fixed padding with length errors and dynamic padding.
- Added exact-span scoring, preserving sentence boundaries.
- Added validation-selected checkpoints and separate test evaluation.
- Seeded model initialisation and shuffling, not only the qualitative sample.
- Added RoBERTa prefix-space configuration for pretokenised input.
- Added safe checkpoint format, offline integration tests and CI.
- Added English documentation and explicit historical evidence labels.

The rewrite uses a consistent default maximum length of 512. Most original
variants used 128 while Q1 relied on tokenizer defaults. It uses gradient
clipping and full precision, and frozen mode disables encoder dropout. These
changes make the public implementation a revised experiment, not an exact
reproduction of the coursework run.

AI assistance was used for the public refactor, tests and English documentation.
No new benchmark metric was generated by that editing process. Historic scores
are copied from the report text and remain marked as not rerun. Numerical values
for frozen BERT, chunking and RoBERTa are absent rather than estimated.

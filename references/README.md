# References

- Devlin, Chang, Lee and Toutanova (2019). [BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding](https://aclanthology.org/N19-1423/). Model background.
- Tjong Kim Sang and De Meulder (2003). [Introduction to the CoNLL-2003 Shared Task: Language-Independent Named Entity Recognition](https://aclanthology.org/W03-0419/). Dataset and task context.
- Liu et al. (2019). [RoBERTa: A Robustly Optimized BERT Pretraining Approach](https://arxiv.org/abs/1907.11692). Alternative pretrained model background.
- Hugging Face. [Token classification, Transformers 4.57.1](https://huggingface.co/docs/transformers/v4.57.1/tasks/token_classification). Subword alignment, masked labels and data collation.
- Hugging Face. [RoBERTa, Transformers 4.57.1](https://huggingface.co/docs/transformers/v4.57.1/model_doc/roberta). Pretokenised input and prefix-space behaviour.
- Nakayama. [seqeval](https://github.com/chakki-works/seqeval). Strict IOB2 span evaluation.
- scikit-learn. [Balanced accuracy](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.balanced_accuracy_score.html). Terminology used to describe the original scripts.

External sources explain the methods. They do not validate this project's
historical scores. The public implementation and local verification were
prepared on 16 October 2026.
